# F02 — CI evidence and merge procedure

## Implemented scope

The foundation workflow runs the build, plan/policy checks, registered unit tests, an independently installed package consumer, actual test shards with a negative assertion control, and the npm dependency audit. It retains command outcomes and report hashes with the tested source identity. The always-run `engine-required` job rejects a failed prerequisite.

Browser, service integration and migration suites are explicitly not applicable at this foundation stage. Their activation cards and reasons are in `docs/ci/scopes.json`. Provider credentials are not referenced by ordinary CI.

## Local verification

The implementation was exercised with Node 24.19.0 and npm 11.9.0. The complete local sequence passed all six required commands. The tooling run reported 71 individual named assertions; the package's public ESM assertion also ran. An intentional failing assertion returned exit 1 both without sharding and in its affected shard. The independent consumer installed the built tarball outside the workspace and checked runtime and declaration resolution. The observed dependency audit reported zero advisories.

Local reports remain marked `mode: local` and `complete: false`; dirty source cannot establish hosted acceptance. Source review includes the environment allowlist, report retention, exact command vectors, current-commit identity, dependency audit errors and application package boundaries. See [separate security review](../security/F02.md).

## Hosted acceptance receipt

Hosted acceptance is pending when this file is introduced. The PR must retain an actual deliberately failing required-check run, a repaired current candidate with fresh passing checks, a separate review naming that candidate, and the observed merge. Applicable main checks are verified afterward. Immutable run, artifact, head/base/tested revision, review and merge identities are recorded after observation; workflow source and local fixtures do not stand in for them.

The deliberate failing candidate `5cceebb3d7a38e39dd1adc6e9dd1674b661fe9b2` was observed in [PR #2](https://github.com/neophilism/Browser-VR-Engine/pull/2). [Run 39072725652](https://github.com/neophilism/Browser-VR-Engine/actions/runs/39072725652) failed both `engine-foundation` (job 117513490514) and `engine-required` (job 117513558514). The log identified the deliberate assertion and reported 72 tooling tests with one failure; report upload succeeded. The failed candidate was not merged. The next candidate removes that test control and requires fresh checks and review.

The repository's observed main protection was disabled at F01 bootstrap, with no required review or status contexts. This change implements the procedural gate and preserves actual settings; it does not claim that workflow YAML configured GitHub branch protection.
